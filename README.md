# Unified Support Dashboard

Unified ticket management for Jira and ServiceDesk Plus (Helpdesk), with AI-powered triage, sentiment analysis, knowledge base, and custom reporting.

## Stack
- Frontend: React 18 + TypeScript + Vite
- Backend: Node.js 20 + Express + TypeScript
- Infrastructure: AWS CDK (ECS Fargate, DynamoDB, SQS, Bedrock)
